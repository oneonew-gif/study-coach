# 各课出题规律与备考要点（模板）

**这是空模板 —— 每个使用者的课程不同，内容要自己攒。** 文件位置：`<库根目录>/course-rules.md`。
Agent 在线三「备考冲刺」时会读它来决定出题方向。

---

## 怎么填

三个来源，按可信度排序：

1. **课程大纲原文**（`materials/` 里的 outline / assessment 文件）—— 题型、分值、考核方式写得很死，最权威
2. **第一节课的说明** —— 老师通常会讲「这门课怎么考、考什么、我出题的习惯」
3. **平时累积** —— 每讲笔记里标 ★★ 的内容、老师反复强调的东西，逐步沉淀到「高频考点」

**填不出来就留空，不要编。** 空着的效果是「Agent 用通用方法出题」；编错的效果是「复习方向被带偏」。

---

## 每门课要回答的问题

### 1. 考试形式
- 期末考 / Quiz 在什么时候？占总分多少？
- 闭卷还是开卷？多长时间？
- 有几道题？什么题型（选择 / 简答 / 论述）？分值怎么分？

### 2. 出题素材来源 ← **最关键的一栏**
- 题目从**课件**出，还是从**教材**出，还是从**学生自己交的作业/讨论**里出？
- 有没有「老师本人的研究是考点」这种情况？如果有，指定的阅读里有多少篇是他自己的？
- 有没有历年题 / 样题可参考？

**这一栏决定复习效率。** 如果选择题完全基于课件，那就该背课件原词；如果考的是教材章节，那读课件没用。

### 3. 高频考点（逐步累积）
- 每讲笔记里标 ★★ 的自动沉淀到这里
- 老师反复强调的、课堂上说过「这个会考」的，优先

### 4. 备考策略
- 这门课该做什么动作？（背术语 / 刷题 / 概念卡 / 练简答 / 读教材）
- 有没有需要提前准备的（如现场讨论、随堂测）？

### 5. 素材位置
- 课件在 `materials/` 的哪个命名前缀下？
- 录音转写在 `transcripts/` 的哪个课次目录？
