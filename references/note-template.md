# 复习笔记标准模板

**一份文件内含中文版 + 英文版两个部分**，不要拆成两个文件。语言按 `WORKFLOWS.md` 配置，默认中英双版。

## 标记约定

| 标记 | 含义 |
|---|---|
| `★` | 考点 |
| `★★` | 本讲最重要、必考 |
| `🚨` | 作业 / 考试情报，直接影响得分 |
| **粗体** | 必背内容（定义、人名年份、数字、术语） |
| 引号内英文原话 | 老师课堂原话，有出题指示意义 |

---

## 写作规则

1. **双源交叉**：课件是权威骨架，录音是考点信号。两者冲突**以课件为准**；老师口述但课件没有的内容，单独放进「课堂口头补充」一节，**不要混进课件结构里**。
2. **数字、日期、人名、年份一律精确保留**，不做四舍五入、不做同义改写。统计口径、样本量、百分比要写全。
3. **英文版术语必须用课件原词**：课件写 `adolescent-limited` 就不能写 `youth-restricted`；写 `joint construction of meaning` 就不能写 `co-construction of meaning`。英文版可以比中文版精简，但**术语密度不能降**。
4. **中文版按知识点分节编号**，一节一个主题。不要用「第一部分 / 第二部分」这种无信息量的标题。
5. **自测题覆盖全部标 ★ 的内容**，10–15 题为宜；答案用 `<details><summary>参考答案</summary>` 折叠。
6. **作业说明按官方原话级保留**，单独标 🚨 放在最前面（评分构成、字数、格式、提交方式、红线）。
7. **来源可追溯**：每个关键结论都应能指回具体课件页或录音片段。不确定的写「待确认」，不要含糊带过。

## 文件命名与存放

命名规则由 `WORKFLOWS.md` 定义，默认：

- 复习笔记：`<课程代码>_第N讲复习笔记.md`
- 课前预习包：`<课程代码>_WeekN课前预习包.md`
- 中英文讲次对应：中文侧 `第一讲 / 第二讲 / …`，英文侧标题写 `Lecture N`

存放目录：`<库根目录>/notes/`

## 背单词模块 · 填表纪律

复习笔记末尾固定有「背单词」一节（中文版末尾、英文版之前），是**词的档案页**，与线五词库（`vocab.sh`）打通：

1. **收词依据四条（按优先级）**：① 录音转写里老师重复 ≥3 次的英文术语 ② 本讲自测题里出现的词 ③ 跨讲复现的高频词（上一讲也在用） ④ 课件新术语。「为什么重要」列**必须写依据**，填不出依据的词不上表——空着比硬凑强。
2. **数量纪律：每讲 3–8 个，宁缺毋滥**。这是复习笔记的附录，不是单词书。
3. **用户给的词同样进表**：出笔记对话里随口给 / 读笔记时补 / 贴文本点名——「为什么重要」列写「使用者指定」。
4. **状态列只写两个静态值**：`待确认` / `已在词库 · 盒 N`。这是**生成笔记那一刻的快照**——之后背词进度变了**不回头改笔记**，进度永远只活在 `vocab.json`。
5. **收词确认一次到位**：交付笔记时列出模块表里的词，问一句「收进词库吗？」——用户确认后批量入库（已在上表的词不重复收）。模块表 = 收词箱的可见化，不再有额外的收词回合。
6. **去重**：入库时按词查重，已在词库的词标「已在词库 · 盒 N」，不重复入库。

## 课前预习包的区别

预习包面向**还没上的课**，所以：

- 重点在**术语表**（英→中，含课件原词拼写），因为预习阶段最需要的是看懂材料
- 列出**预计考点**与**带着读的问题**，而不是总结
- 不含自测题（还没学，测不了），改成「读完这些材料你应该能回答的问题」
